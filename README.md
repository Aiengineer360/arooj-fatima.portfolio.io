# 🚀 Arooj Fatima — AI Engineer Portfolio

A futuristic, AI-themed personal portfolio website showcasing professional experience, AI projects, technical skills, certifications, awards, and contact information.

This portfolio represents the professional profile of **Arooj Fatima**, an AI Engineer specializing in:
